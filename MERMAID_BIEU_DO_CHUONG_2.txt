Hình 2.9: Biểu đồ trình tự use case thuê API QR
```mermaid
sequenceDiagram
  autonumber
  actor Dev as Developer
  participant Web as Web SmartQR
  participant API as API SmartQR

  participant Pay as PayOS

  Pay-->>API: Webhook thanh toán thành công

  Key->>DB: Lưu keyHash, quota, scopes
  Key-->>API: Trả key thô một lần
  API-->>Web: Kết quả kích hoạt và API key
```

Hình 2.13: Biểu đồ trình tự use case tạo mã QR
```mermaid
sequenceDiagram
  autonumber
  actor Client as Ứng dụng tích hợp
  participant API as QR API
  participant Guard as API Key Guard
  participant QR as QR Platform Service
  participant DB as PostgreSQL
  participant Sign as QR Signing
  participant Hook as Webhook Queue

  Client->>API: POST /api/v1/qr-codes
  API->>Guard: Kiểm tra X-API-Key và scope qr:create
  Guard-->>API: Key hợp lệ, còn quota
  API->>QR: Tạo mã QR theo payload
  QR->>Sign: Ký JWT QR, sinh jti
  Sign-->>QR: qrJwt và jti
  QR->>DB: Lưu ExternalQrCode
  DB-->>QR: QR đã tạo
  opt Thuê bao có webhook
    QR->>Hook: Enqueue qr.created
  end
  QR-->>API: ID, code, qrJwt, SVG URL, expiresAt
  API-->>Client: 201 Created
```

Hình 2.19: Biểu đồ trình tự use case gửi webhook
```mermaid
sequenceDiagram
  autonumber
  participant Domain as QR / Ticket Service
  participant DB as PostgreSQL
  participant Queue as Webhook Worker
  participant Safe as Safe HTTP
  participant Client as Hệ thống khách hàng
  participant Log as WebhookAttempt

  Domain->>DB: Tạo WebhookEvent và dedupeKey
  Queue->>DB: Lấy event đến hạn, khóa xử lý
  Queue->>Safe: Gửi HTTPS POST kèm signature
  Safe->>Client: Event body + X-Webhook-Signature
  Client-->>Safe: HTTP response
  Safe-->>Queue: Status code / lỗi
  Queue->>DB: Cập nhật trạng thái event và attempts
  Queue->>Log: Lưu statusCode, durationMs, error
  alt Gửi thành công
    Queue->>DB: Đánh dấu deliveredAt
  else Gửi lỗi và còn lượt thử
    Queue->>DB: Lên lịch retry
  else Gửi lỗi quá số lần
    Queue->>DB: Đánh dấu thất bại và tạo thông báo
  end
```
